## 二、一句话介绍

**法元（Faron）· 文书智能体「小元」**：一个跑在律师 / 法务本机上的「办案数字员工」——听懂委托 → 自主检索内置的 **152,940 条真实日美官方法条**（装机即用、不联网导入）→ 起草并质检 → 交付**可溯源、可双击打开的 .docx 文书**，全程数据不出本机；交付物中的每一条法条引用都由**代码级规则逐条对账**（未覆盖自动点名，非模型自述），评委可当场抽查、也可当场用反例验证。

主场景：**涉外 / 跨境法律业务**（中日合资、赴美投资、跨境贸易与出口合规等）。

## 三、产品当前形态（赛事版 0.7.3 实况）

**桌面应用 —— 左侧导航 8 个功能版块**

1. **首页总览**：今日待办、统计卡、超期提醒、常用入口、最近文书
2. **法规查询**：双模式 —— 「📚 按法浏览」（国家 → 领域 → 整部法，双语名称、条文跳转、打印 / 另存 PDF、正文可选中复制、中文检索可命中译名与译文）与「🔍 关键词检索」（FTS5 优先、LIKE 兜底）
3. **模板库**：内置法律文书模板、分类筛选、自建模板
4. **文书智能体「小元」**：5 类任务（**合同审查 / 起诉状 / 证据目录 / 质证意见 / 代理词**）；可编辑计划卡、自主工具调用循环、人工确认闸门、任务历史续跑；知识图谱驱动规划与「法条适用性」二段校验；多模态材料输入（DOCX / PPTX / XLSX / TXT / MD / CSV 本地离线提取，PDF / 图片由支持文件输入的模型转录并标注「非原文」）；交付物导出 .docx（证据目录为 Word 原生表格）
5. **翻译**：15 种目标语种与自动检测；文档全文翻译（docx / pptx / xlsx / txt / md / csv 本地提取，pdf 与图片由模型转录）；译文可导出 Word 或 Markdown
6. **待办提醒**：增删改查、截止时间、提前提醒、到期系统通知、多视图筛选
7. **数据设置**：AI 接口配置、日间 / 夜间主题、手动与自动备份配置、数据库还原
8. **数据导入**：Excel 批量导入法规 / 模板（法规支持可选译文列）

> 侧栏第 9 项「**自我进化**」是 **0.8.0 规划（联邦配方进化）方案稿的可视化页**，带「方案稿」角标，**不计入上述 8 项已实现功能清单**（口径见第七节）。

**配套形态**

- **桌面悬浮球助手**（Electron）：任意应用内选中文字 → 翻译 / 关联查找法规（走主程序本地法库）/ 询问 AI；抓取模式可切换；多套皮肤；可将选中文字推送给「小元」预填任务材料
- **产品演示站**：单文件 HTML、零依赖，**可离线双击打开**（本包 `04` 目录即此文件）；含引用自检实验室、知识图谱、品牌与设计理念、自我进化实验室等可交互板块
- **移动端演示 APK**：法元的轻量伴随入口（生态演示，范围见第八节）

## 五、三个值得重点看的技术点

1. **确定性引用自检（本作品最硬的差异点）**
   交付物合成与质检环节由**执行器代码**把正文里的条文引用（中文 / 日文「第X条（之Y / のY）」、美国法典「§NN」等格式）逐条与「本次工具真实返回的法条」比对：**未覆盖项自动点名、不计为有效引用**。它不依赖模型「自称查过」，结论与模型输出内容无关——所以可以用反例验证（演示站「引用自检实验室」与演示视频 S5 镜头均可现场复现）。

2. **知识图谱驱动的规划与编排**
   内置本地知识图谱（案由 → 构成要件 → 请求权基础 / 证据 / 争点，人工策展种子 + 任务观测候选边）：任务材料先命中案由，再由图谱骨架生成计划卡，**避免要件遗漏、自动限定法域**；交付物叠加「法条适用性」二段校验；任务真实命中的法条登记为低置信度候选边，**人工确认后才作为后续规划依据**。

3. **本地优先 + 可验收交付闭环**
   SQLite 单机运行（WAL + FTS5），数据不出本机；交付物为固定五段式并导出 .docx（含 Word 原生表格），可打开、可二次编辑、可归档，任务与文书自动记入「最近文书」；API Key 密文落盘（避免明文暴露）。

## 六、装机与上手（三步）

1. **安装**：运行 `法元_0.7.3_赛事版_x64-setup.exe`。若出现 Windows SmartScreen 提示，选择「更多信息 → 仍要运行」（安装包未做代码签名，与文件完整性无关，可用 `05-安装包与移动端/说明.md` 中的 SHA256 校验）。
2. **首启**：首次启动自动装载内置法库（约 1 分钟，过程可见）——装完即可检索，不需要任何联网导入。
3. **体验建议路径**：法规查询（按法浏览 → 打开一部整法 → 条文跳转 → 查看译文）→ 文书智能体（制定计划 → 开始执行 → 看工具调用与引用清单 → 质检结论 → 导出 .docx）。

> **关于模型接口（如实说明）**：未配置模型接口时，**法规浏览与检索、模板库、待办提醒、数据导入可完整使用**；**文书智能体进入演示模式**（计划由预设流水线给出，但**工具调用真实执行**，界面明确标注「演示模式」）；**翻译与文档全文翻译需先在「数据设置 → AI 接口」配置模型接口**后使用。

## 七、口径边界（如实说明，避免误解）

1. **「自我进化」页不是已落地功能**：它是 0.8.0 规划方案稿的可视化页。其中加权聚合、差分隐私、K 匿名、白名单体检、指纹与 A/B 采纳判定为**真实实现**，客户端行为为**协议仿真**；**它不是强化学习**（无策略梯度、无价值函数），页面内含逐项对照表。本页不计入已实现功能清单。
2. **中文法库未内置**：中文全量法条按权威公开源接入属后续路线图；当前中文能力见第四节，不做「已覆盖中文全量」的表述。
3. **移动端是生态演示**：不含桌面端全量法库、Excel 导入、文书智能体任务与 .docx 交付。
4. **场景与泛用性**：「验证期聚焦涉外」≠ 能力上限——任务流水线是模板化步骤引擎（新增任务类型 = 新增一条模板），法域可扩展，产品定位为「法域 × 文书场景」平台。
5. **未实测的性能数字不作承诺**：本包材料不写未实测的性能指标；如需性能佐证，以现场演示与真机运行结果为准。
6. **法规内容边界**：法条原文版权归各官方来源，应用仅作本地检索与引用，结论以官方文本为准，不构成法律意见。
