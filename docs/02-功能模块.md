# 02 · 功能模块说明

本文档按左侧导航的 8 个版块逐一说明功能、实现方式与完成状态。所有结论均来自 `0.1.0` 版本源码。

状态图例：✅ 已实现可用 ｜ 🟡 部分实现（有占位或待接入） ｜ ⬜ 仅骨架/占位

---

## 1. 首页总览（/home）— ✅

**入口**：`src/views/Home.tsx`

功能：

- 欢迎语与当前日期（`2025年X月X日 星期X` 格式）。
- 统计卡：今日待办、进行中（未完成总数）、已超期（超期时标红）。
- 超期横幅：存在超期待办时显示，可跳转待办页。
- 今日待办：列出当天到期的未完成待办（最多 5 条），可勾选完成。
- 最近处理的文书：**占位**，提示待「模板库/文书」功能接入后展示。
- 常用功能：8 个版块的快捷入口网格。

**数据来源**：`useTodos`（桌面走 `todos_list`，浏览器走 localStorage）。

## 2. 法规查询（/laws）— ✅（数据源待扩充）

**入口**：`src/views/Laws.tsx`、`src/hooks/useLaws.ts`

功能：

- 关键词搜索，匹配范围：篇名、条文号、章节、条文内容（SQL 为 `LIKE '%keyword%'`，多字段 OR）。
- 结果按「篇名」分组展示（如《中华人民共和国民法典》），左侧列表、右侧正文阅读。
- 单个命中时自动选中并展开正文；正文展示章节标签、条文号与来源。

**数据源**：数据库 `laws` 表。当前为内置播种的 6 条《民法典》示例条文（来源标注「内置示例」）；正式数据计划通过「数据导入」版块的 Excel 导入（尚未实现）。页面也明确提示「数据源：内置示例 / 待 Excel 导入」。

**后端命令**：`laws_search`。

## 3. 模板库（/templates）— ✅

**入口**：`src/views/Templates.tsx`、`src/hooks/useTemplates.ts`

功能：

- 分类筛选：chips 按模板分类过滤（内置 5 类：授权文书、诉讼文书、劳动仲裁、函件、合同）。
- 内置模板（`built_in=1`，5 份）：
  - 授权委托书
  - 民事起诉状
  - 劳动仲裁申请书
  - 律师函模板
  - 房屋租赁合同（简）
- 自建模板：表单填写标题、分类、正文（`____` 下划线为待填项约定），保存后入库。
- 删除：仅自建模板可删，内置模板删除会收到「内置模板不可删除」错误提示。
- 详情：右侧展示模板全文（等宽字体），标注文件类型（当前均为 `txt`）。

**后端命令**：`templates_list`、`templates_create`、`templates_delete`。

## 4. AI 助手（/assistant）— ✅（需自备接口）

**入口**：`src/views/Assistant.tsx`、`src/lib/ai.ts`

功能：

- 三种模式（对应三套系统提示词）：
  - **通用**：法律视角专业问答。
  - **审合同**：审查合同条款，指出风险条款、责任失衡、约定不明处并给出修改建议（先风险后建议）。
  - **审质证**：围绕证据合法性、真实性、关联性分析质证要点或起草质证意见。
- 流式对话：调用 OpenAI 兼容 `/chat/completions` 接口（`stream: true`），逐段渲染增量，支持 Ctrl/Command + Enter 发送。
- 大窗口 ⇄ 置顶悬浮窗切换：
  - 「置顶悬浮窗」→ `float_in`：主窗口隐藏，显示 380×500 置顶小窗。
  - 「放大到大窗口」→ `float_out`：恢复主窗口并关闭悬浮窗。
- 会话管理：清空对话；未配置接口时提示前往「数据与设置」填写。

**前置条件**：需在「数据与设置」中配置 base_url、API Key、模型名（默认 `gpt-4o-mini`），兼容任意 OpenAI 风格网关。未配置时页面给出引导链接，发送被拦截并提示。

**后端命令**：`float_in`、`float_out`。

## 5. 翻译（/translate）— ✅

**入口**：`src/views/Translate.tsx`、`src/lib/translate.ts`

功能：

- 语言：15 种常用语种 + 源语言「自动检测」，目标语言不可选自动检测。
- 双引擎：
  - **免费接口（默认）**：Google translate gtx 端点，无需 Key，开箱即用。
  - **付费接口**：在「数据与设置」选择并配置后启用，走 OpenAI 兼容接口，由模型直接输出译文。
- 交互：语言互换（自动检测侧不可作为目标）、Ctrl/Command + Enter 快速翻译、一键复制译文、字数统计。
- 页面实时显示当前使用的引擎（免费接口 / 付费接口）。

## 6. 待办提醒（/todo）— ✅（弹窗触发待实现）

**入口**：`src/views/Todo.tsx`、`src/hooks/useTodos.ts`

功能：

- 新建待办：标题（必填）、备注、截止时间（datetime-local）、提前提醒分钟数、桌面弹窗开关。
- 编辑：编辑面板支持修改全部字段（`todos_save` 全字段保存）。
- 完成切换：列表勾选，已完成行置灰。
- 删除：带确认的删除按钮。
- 筛选视图：全部 / 进行中 / 已完成 / 已超期（带计数）。
- 状态标签：到期时间自动标注「已超期」（红）/「即将到期」（黄，进入提醒窗口）/「到期」。
- 侧栏联动：未完成且有截止时间的待办数量以 badge 显示在「待办提醒」导航项上。
- 首页联动：今日待办、超期横幅、统计卡均来自本版块数据。

**提醒机制现状**：`remind_minutes`（提前提醒）与 `desktop_popup`（桌面弹窗开关）均已入库并展示，但**实际的定时弹窗触发逻辑尚未实现**，当前仅为数据存储与展示。

**后端命令**：`todos_list`、`todos_create`、`todos_update`（局部更新 done/title，保留兼容）、`todos_save`（全字段）、`todos_delete`。

## 7. 数据设置（/settings）— ✅（自动备份调度待实现）

**入口**：`src/views/Settings.tsx`、`src/hooks/useSettings.ts`

功能：

- **AI 助手配置**：接口地址 base_url、模型名、API Key（密码框）。留空则 AI 助手不可用。
- **翻译配置**：选择「内置免费接口」或「自定义付费接口」；付费时填写接口地址与 API Key。
- **数据备份**：
  - 手动备份：指定目录，`backup_now` 将 `legal.db` 复制为 `legal-<时间戳>.db`。
  - 自动备份：开关 + 周期（天）+ 目标目录。**注意：定时调度逻辑尚未实现**，当前仅持久化配置；代码中已对「开启自动备份但未填目录」给出警告提示。
  - 还原：指定备份 `.db` 文件路径，`restore` 覆盖当前数据库，提示「还原成功，重启后生效」。
- **其它偏好**：新建待办默认启用桌面弹窗提醒。

**存储**：全部以键值对存入 `settings` 表（浏览器预览降级到 localStorage）。键名常量见 `useSettings.ts` 的 `KEYS`。

**后端命令**：`settings_get`、`settings_set`、`backup_now`、`restore`。
