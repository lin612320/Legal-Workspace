## 1. 首页总览（/home）— ✅

**入口**：`src/views/Home.tsx`

功能：

- 欢迎语与当前日期（`2026年X月X日 星期X` 格式）。
- 统计卡：今日待办、进行中（未完成总数）、已超期（超期时标红）。
- 超期横幅：存在超期待办时显示，可跳转待办页。
- 今日待办：列出当天到期的未完成待办（最多 5 条），可勾选完成。
- **最近处理的文书**：读取 `documents`（桌面）/ localStorage（浏览器）的文书记录（智能体交付物落点），行内展示文件类型、路径与时间，可一键「打开」（系统默认程序）或「删除」；点击面板头部可跳转文书智能体。
- 常用功能：左侧导航全部版块（10 个）的快捷入口网格。

**数据来源**：`useTodos`（桌面走 `todos_list`，浏览器走 localStorage）+ `useDocuments`（桌面走 `documents_list`）。

## 2. 法规查询（/laws）— ✅（内置日美法库 + 国家筛选 + FTS5）

**入口**：`src/views/Laws.tsx`、`src/hooks/useLaws.ts`

功能：

- **内置法库**：0.3.2 起安装包内嵌日美法律数据库（预置库约 467 MB，git 忽略），条文级共 **152,940 条**（日本 95,897 条 + 美国 57,037 条 + 中国内置示例 6 条）；首次启动自动装载，装机即用（详见 [03-数据库设计.md](03-数据库设计.md)）。
- **国家筛选下拉**：🌐 全部国家 / 🇯🇵 日本 / 🇺🇸 美国 / 🇨🇳 中国（带国旗与各库条数，来自 `laws_countries`）。
- **重点法规预览**：进入页面或切换国家后，预显示该国条文最多的前 8 部法规（`laws_country_preview`），点击即在所选国家内检索其法名。
- **按需关键词检索**：页面不再挂载即全量加载条文；输入关键词才请求 `laws_search`，命中最多返回前 500 条（提示细化缩小）。关键词 ≥ 3 字走 FTS5 全文检索（BM25 相关度），否则 / 异常时回退 LIKE；国家归属在 SQL 层按标题 / 来源特征判定（见 [01-技术架构.md](01-技术架构.md) §2.3）。
- 结果按「篇名」分组展示，左侧列表（条文号 + 正文摘要）、右侧正文阅读；单条命中自动展开。正文展示章节标签、条文号与来源。
- 未命中提示：「试试更短的关键词（如 “契約”“遺留分”“商标”“contract”），或切换国家/全部国家」。

**后端命令**：`laws_count`、`laws_search`、`laws_countries`、`laws_country_preview`、`law_by_id`。

## 3. 模板库（/templates）— ✅

**入口**：`src/views/Templates.tsx`、`src/hooks/useTemplates.ts`

功能：

- 分类筛选：chips 按模板分类过滤（内置分类：授权文书、诉讼文书、劳动仲裁、函件、合同）。
- 内置模板（`built_in=1`，5 份，见 [03-数据库设计.md](03-数据库设计.md)）：授权委托书、民事起诉状、劳动仲裁申请书、律师函模板、房屋租赁合同（简）。
- 自建模板：表单填写标题、分类、正文（`____` 下划线为待填项约定），保存后入库（`built_in=0`，标「自建」）。
- 删除：仅自建模板可删；内置模板删除收到「内置模板不可删除」提示。
- 详情：右侧展示模板全文（等宽字体），标注文件类型（当前均为 `txt`）。

**后端命令**：`templates_list`、`templates_create`、`templates_delete`。

## 4. AI 问答（/assistant）— ✅（需自备 / 可配置模型接口）

**入口**：`src/views/Assistant.tsx`、`src/lib/ai.ts`（0.4.0 起由「AI 助手」更名为「AI 问答」，定位即时法律咨询）

功能：

- 三种问答模式（对应三套系统提示词 `SYSTEM_PROMPTS`）：
  - **通用**：法律视角专业问答。
  - **审合同**：审查合同条款，指出风险条款、责任失衡、约定不明处并给出修改建议（先风险后建议）。
  - **审质证**：围绕证据合法性、真实性、关联性分析质证要点或起草质证意见。
- **多会话 + 持久化**：桌面版大窗口提供会话栏（新建 / 切换 / 重命名 / 删除），持久化到 SQLite（`chat_sessions` / `chat_messages`）；首条消息自动用提问生成会话标题；浏览器预览降级到 localStorage（无会话栏 UI）。
- **RAG 检索注入**：发送前按提问关键词检索本地法库（桌面走 `laws_search`，浏览器搜示例），取前 4 条作为「相关法条参考」注入 system 提示，要求模型「可引用、不得编造」。
- 流式对话：OpenAI 兼容 `/chat/completions`（`stream: true`），逐段渲染增量，支持 Ctrl/Command + Enter 发送、生成中「停止」（AbortController）。
- Markdown 渲染：代码块、行内代码、加粗、列表、标题、空行分段。
- 大窗口 ⇄ 置顶悬浮窗：悬浮窗加载 `#/assistant?float=1` 复用同一组件；大窗口与悬浮窗通过 localStorage 键 `workbench:chat` + `storage` 事件实时同步会话与消息（`float_in` / `float_out` 只做显隐切换）。
- **→ 文书智能体交接桥**：回答后可点「📄 生成文书任务」，把最近一轮「问题 + AI 结论」写入 `workbench:agentHandoff` 并跳转 `/agent`（审质证 → `cross_exam`，其余 → `review`），实现「咨询 → 交付」闭环。
- 悬浮球推送联动：悬浮球推送的选中文字自动填入输入框。

**前置条件**：AI 问答需要模型接口可用。在「数据设置」配置 base_url / API Key / 模型名（默认 `gpt-4o-mini`，兼容任意 OpenAI 风格网关）；未配置时发送被拦截并提示前往「数据与设置」。

**后端命令**：会话与消息类 `chat_sessions_*`、`chat_history_*`，窗口类 `float_in` / `float_out`。

## 5. 文书智能体（/agent）— ✅（演示模式可用；未配置模型时工具仍真实执行）

**入口**：`src/views/Agent.tsx`、`src/lib/agent.ts`、`src/lib/tools.ts`（0.4.0 新增；0.4.1 人设命名「小衡」）

定位：把「对话助手」升级为可交付成果的「数字员工」。内置三条流水线：

- **合同审查 → 《审查意见书》**（`review`）
- **起诉状起草 → 《民事起诉状》草稿**（`lawsuit`）
- **质证意见**（`cross_exam`）

功能与实现方式：

- **任务理解与规划**：模型结构化输出「计划卡」（可编辑步骤 JSON，含检索关键词与国家）；未配置模型时自动进入**演示模式**（预设流水线，工具步骤仍真实执行），保证无 Key 也能演示全流程。
- **自主工具调用循环（function calling）**：检索类步骤由模型在工具间自主决策连续调用，直至给出结论（`runAgenticToolStep`，≤ 6 轮）；全程只引用工具真实返回的法条（可溯源、防编造）。五个工具：`laws_search` / `law_by_id` / `laws_country_preview` / `template_load` / `translate_text`，结果带 `refs` 引用法条。
- **多角色接力（P3 雏形）**：步骤按「规划 → 检索员 → 起草员 → 质检员」角色标注（独立 system 提示词），UI 以接力节点可视化。
- **人工确认闸门**：计划卡可编辑；步骤可标记「需人工确认」；执行支持暂停 / 继续 / 失败即停，附分步执行日志与累计引用法条展示。
- **任务状态机落库**：任务与步骤状态持久化到 `tasks` / `task_steps` / `task_artifacts`；「任务历史」列表（桌面读 SQLite，浏览器保留最近快照）可一键载入查看进度 / 续跑 / 删除。
- **确定性引用自检（Unreleased，2026-09-06）**：质检（role=qa）不再只依赖模型「自查」——QA 步骤末尾由代码强制追加 `auditCitations` 结论：按中文/日文「第X条（之Y/のY）」、美国「§NN」等格式识别正文条文号，逐条判定是否能在「本次工具真实返回」的法条中找到对应条文；未覆盖项**点名提示人工核实**，不视为有效引用。
- **可验收交付**：交付物 Markdown 实时预览 → 桌面版一键导出 .docx（零依赖 OOXML，`docx.rs`）并记入首页「最近文书」+ `task_artifacts`，可「打开 / 在文件夹中显示」；浏览器版下载 .md + 本地（演示）文书。
- 悬浮球推送的选中文字在智能体页自动预填为任务材料。

**后端命令**：`task_create` / `task_list` / `task_get` / `task_set_status` / `task_delete` / `task_steps_save` / `task_step_update` / `task_artifact_add` / `mem_save` / `mem_list` / `law_by_id` / `documents_list` / `document_save` / `document_delete` / `docx_export` / `open_file` / `reveal_in_folder`。

## 6. 翻译（/translate）— ✅

**入口**：`src/views/Translate.tsx`、`src/lib/translate.ts`

功能：

- 语言：16 项语种列表（含「自动检测」，共 15 种目标语种），源语言可选自动检测，目标语言不可选自动检测；支持语言互换。
- 双引擎：
  - **免费接口（默认）**：Google translate gtx 端点，无需 Key，开箱即用。
  - **付费接口**：在「数据与设置」选择并配置后启用，走 OpenAI 兼容接口，由模型直接输出译文。
- 交互：Ctrl/Command + Enter 快速翻译、一键复制译文、字数统计。
- 页面实时显示当前使用的引擎（免费接口 / 付费接口）。
- 智能体亦内置 `translate_text` 工具复用该引擎（免费接口，无需 Key）。

## 7. 待办提醒（/todo）— ✅（桌面到期系统通知已实现）

**入口**：`src/views/Todo.tsx`、`src/hooks/useTodos.ts`

功能：

- 新建待办：标题（必填）、备注、截止时间（datetime-local）、提前提醒分钟数、桌面弹窗开关。
- 编辑：编辑面板支持修改全部字段（`todos_save` 全字段保存）。
- 完成切换：列表勾选，已完成行置灰。
- 删除：带确认的删除按钮。
- 筛选视图：全部 / 进行中 / 已完成 / 已超期（带计数）。
- 状态标签：到期时间自动标注「已超期」（红）/「即将到期」（黄，进入 `remind_minutes` 提醒窗口）/「到期」。
- 侧栏联动：未完成且有截止时间的待办数量以 badge 显示在「待办提醒」导航项上。
- 首页联动：今日待办、超期横幅、统计卡均来自本版块数据。

**提醒机制现状（已实现）**：`desktop_popup` 与 `remind_minutes` 入库；桌面版由 Rust 后台线程每 30 秒轮询 `todos`，对「未完成 + 弹窗开启 + 有到期时间 + `due_at <= now + remind_minutes` 且 `last_notified_due` 与本次到期时间不同」的待办发系统通知（标题「律衡 · 待办提醒」），并回写 `last_notified_due` 防止同一到期时间重复提醒。浏览器预览无该后台轮询。

**后端命令**：`todos_list`、`todos_create`、`todos_update`（局部更新 done/title，保留兼容）、`todos_save`（全字段）、`todos_delete`。

**入口**：`src/views/Focus.tsx`

## 9. 数据设置（/settings）— ✅（自动备份仅配置、无定时调度）

**入口**：`src/views/Settings.tsx`、`src/hooks/useSettings.ts`

功能：

- **AI 接口配置**：接口地址 base_url、模型名、API Key（密码框）。留空则 AI 问答 / 智能体不可用（进入演示模式）。API Key 落盘前经 XOR+hex 混淆（`enc:` 前缀，桌面端 Rust 再加密一次，读取解密）。
- **翻译配置**：选择「内置免费接口」或「自定义付费接口」；付费时填写接口地址与 API Key。
- **数据备份**：
  - 手动备份：指定目录，`backup_now` 将 `legal.db` 复制为 `legal-<时间戳>.db`。
  - 自动备份：开关 + 周期（天）+ 目标目录。**注意：仅为配置持久化，尚无定时调度执行**（真实缺口，见 [05-优化路线图.md](05-优化路线图.md)）；开启自动备份但未填目录时页面给出警告。
  - 还原：指定备份 `.db` 文件路径，`restore` 覆盖当前数据库，提示「还原成功，重启后生效」。
- **其它偏好**：新建待办默认启用桌面弹窗提醒。

**存储**：全部以键值对存入 `settings` 表（浏览器预览降级到 localStorage）。键名常量见 `useSettings.ts` 的 `KEYS`（`ai.base_url` / `ai.api_key` / `ai.model` / `translate.provider` / `translate.api_key` / `translate.base_url` / `backup.auto` / `backup.interval_days` / `backup.target_dir` / `pref.default_popup`）。

**后端命令**：`settings_get`、`settings_set`、`backup_now`、`restore`。

## 10. 数据导入（/import）— ✅（桌面版 Excel 导入已实现）

**入口**：`src/views/Import.tsx`（0.1.0 时为占位页；Excel 解析已接入，不再是占位）

功能：

- 数据源选择：法规（laws 表）或模板（templates 表）。
- 输入 .xlsx 文件完整路径 → 开始导入（仅桌面版可用；浏览器预览提示不可用）。
- 表头支持中英文列名：
  - 法规：`title（标题）/ chapter（章节）/ article_no（条文号）/ content（内容）/ source（来源）`。
  - 模板：`title（标题）/ category（分类）/ content（内容）/ file_type（类型）`。
- 只读第一个工作表；`title` 与 `content` 必填，空行 / 缺内容的整行跳过。
- 导入结果反馈「新增 N 条，跳过 M 条」；重复导入不去重（页面提示可先手动备份）。
- 导入的法规 / 模板即时进入法规检索 / 模板库（`laws` 新行由 FTS5 触发器自动同步索引）。

**后端命令**：`import_excel`（内部使用 calamine 解析 .xlsx）。

## 附 2：桌面悬浮球助手（floating-ball，随主程序联动）

`floating-ball/` 是 Electron 33 独立应用，随主程序安装包分发并自动拉起（见 [01-技术架构.md](01-技术架构.md)）：

- 选中文字一键**翻译 / 关联查找 / 询问 AI**；支持多套球皮肤与面板主题、悬停对话气泡。
- 与主程序双向文件桥：主程序经 `%APPDATA%\floating-ball\from-workbench.json` 下发 `show / hide / prefill / translate / quit`；悬浮球把推送文字写入 `to-workbench.json`，主程序 Rust（或 Vite 插件）轮询后以 `ball-push` 事件送达前端。
- 悬浮球也可独立使用（便携版 exe），或自行拉起打包版 `legal-workbench.exe`。
