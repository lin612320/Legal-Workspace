### B. 法规检索 · FTS5（07 §二 #6–10）

> 检索耗时用秒表或 DevTools Network 记录，填入"实测耗时"列；命中数以页面顶部/列表为准。

- #6 国家下拉：🌐/🇯🇵/🇺🇸 切换，记录各国条数与重点法规 Top8 是否正常。
- #7 🇯🇵 关键词 `契約`、`遺留分`：记录命中数（全库含"契約"4,565 行左右）与耗时。
- #8 🇺🇸 关键词 `trademark`、`copyright`：记录命中与耗时。
- #9 1–2 字短词（如 `法`、`税`）：确认自动回退 LIKE 仍出结果、不报错。
- #10 空关键词直接点搜索：确认不请求、不卡顿。
- #6a–6g（07 §二之二，赛事版新增）：「按法浏览」选 🇯🇵 → 截图国家概览与领域分组列表 → 打开整法页（元信息+全文）→ 条文跳转（`103`、中文数字）→ 打印/另存 PDF → 选中正文 Ctrl+C 验证可复制 → 打开美国宪法开「查看译文」逐条核对官方中译 → 检索输入 `宪法` 验证中文命中。逐项留截图并回填 07。

### C. 智能体 · 模型模式（07 §三 #11–18b；已配置可用 Key）

1. #11 进「文书智能体」→ 填入**涉日合资 / 赴美投资示例合同**（建议 ≤4 千字）→「① 制定计划」。确认计划卡出现且来源标注"模型驱动"（非"演示模式"）；编辑一个步骤确认可改。
2. #12「② 开始执行」→ 打开执行日志面板，**数出 ≥3 次真实工具调用**，逐条截图（工具名 + 参数 + 状态）。
3. #13 观察"本次引用法条"列表：篇名 / 条文号 / 来源齐全；点来源能回到法条正文。
4. #14 把某检索步"需人工确认"打开 → 执行到该步停在等待态 → 点「继续」放行。
5. #15 把某步工具参数改成必失败值（如 `law_by_id` 传不存在 id）→ 确认该步标失败、任务 failed、不再继续。
6. #16 完成后「导出 .docx」→「打开文件」→ 记录 Word / WPS 能否打开（截图）。
7. #17 回首页「最近处理的文书」出现该记录，「打开」「删除」可用。
8. #18 刷新/重启应用 → 文书智能体 →「任务历史」→ 载入 → 恢复到上次步骤状态并可继续。
9. #18a 交付物（预览 / 导出的 docx）结构含「四、引用自检（确定性规则校验）」；正常场景结论为"识别 X 处条文号引用 → 与本次工具真实返回对应 X/X（通过）"，截图。
10. #18b **反例验证（关键）**：计划卡新增一步推理/起草步骤，让产出引用一个库内不存在的条文号（如「第 9999 条」）→ 执行到质检 → QA 步骤日志末尾出现【引用自检 · 确定性规则】"需人工核实"并点名；交付物「四」同样点名且不计为有效引用。**截图保存，这是"硬校验非模型自查"的最有力证据。**

### D. 智能体 · 演示模式（07 §四 #19–21a；清空 Key 也能跑）

- #19 清空 Key →「① 制定计划」→ 记录页面明示"演示模式"提示（**现场演示时这句话要口头念出来**）。
- #20 检索步骤填库内真关键词（`契約`）→ 确认工具真实返回（非编造）。
- #21 完成 → 浏览器版「下载 .md」；桌面演示模式导出 .docx 亦可。
- #21a 查看 QA 步骤与交付物「四」是否同样带确定性自检结论（应带）。

### E. 接力可视化与记忆（07 §五 #22–24）

- #22 计划卡上方接力链：规划 → 检索员 → 起草员 → 质检员 状态图截图。
- #23 模型模式下观察各角色产出语气/职责差异（截两条对比）。
- #24 完成一个审查任务后，模型模式再做同类任务 → 记录规划提示或结果是否参考上次任务（向量/关键词召回命中则截图）。

### F. 交付与安全加固（07 §六 #25–27）

- #25 `sqlite3 %APPDATA%\com.legalworkbench.app\legal.db "SELECT key,value FROM settings WHERE key IN ('ai.api_key','translate.api_key');"` → 值均为 `enc:` 前缀、无明文 `sk-`。

## 五、演示前检查单（上场前 5 分钟）

1. 产品已首启一次（法库已装载、FTS 索引已建），演示机离线试跑"检索 + 演示模式全流程"不翻车；
2. 演示词全部取自 07 §七 必命中表（日 `遺留分 / 契約 / 民法`、美 `trademark / bankruptcy`）；
3. 若走模型模式：Key 有效、网络通；若走演示模式：**先念台词"当前未配置模型接口，计划为预设流水线，但工具调用真实执行"**；
4. 反例演示（库外条文号 → 自动点名）已在本机自验一遍，确认预期输出文本；
5. 交付物导出路径可写、Word/WPS 可打开；悬浮球能拉起（托盘在）；
6. 备份好"最近文书"里本次演示产出的 docx，避免现场误删。
