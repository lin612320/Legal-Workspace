# 04 · 开发与构建指南

本文档说明律政工作台的开发环境、常用命令、桌面版构建与已知注意事项。

## 1. 环境要求

| 依赖 | 版本 | 用途 | 备注 |
| --- | --- | --- | --- |
| Node.js | 20+（仓库脚本使用 v24.19.0） | 前端依赖与构建 | 见 `package.json` 与启动脚本 |
| npm | 随 Node.js | 依赖管理 | 仓库自带 `package-lock.json` |
| Rust | 1.77+（`rust-version` 声明） | Tauri 桌面壳编译 | 见 `src-tauri/Cargo.toml` |
| MSVC Build Tools / C++ 构建工具 | 最新 | Windows 下编译 Rust | 见下方说明 |

> 首次在本机构建桌面版时，Rust 工具链与 MSVC 构建工具可用仓库 `.install/` 目录下的安装器：
>
> - `.install/rustup-init.exe` —— Rust 工具链安装器
> - `.install/vs_buildtools.exe` —— Visual Studio Build Tools 安装器
>
> 二者均为官方安装器，直接运行并按提示安装即可。安装后需确保 `cargo`、`rustc` 与 MSVC 链接器在 `PATH` 中。

## 2. 常用命令

项目根目录为 `DEMO/DEMO`（包含 `package.json` 与 `src-tauri/` 的目录）。以下命令均在该目录执行。

```bash
# 安装依赖
npm install

# 启动浏览器预览（仅前端，localStorage 降级数据）
npm run dev          # http://localhost:1420

# 类型检查 + 构建前端产物
npm run build        # tsc && vite build，输出 dist/

# 预览构建产物
npm run preview

# 桌面版开发（自动编译 Rust 并启动应用）
npm run tauri dev

# 打包桌面安装程序（Windows：NSIS / MSI 等）
npm run tauri build
```

### 2.1 关键配置

- **`vite.config.ts`**：开发端口固定 `1420`（`strictPort`），`envPrefix` 同时支持 `VITE_` 与 `TAURI_`，`TAURI_DEBUG` 开启时保留 sourcemap 且不压缩。
- **`src-tauri/tauri.conf.json`**：
  - `build.devUrl` = `http://localhost:1420`，`beforeDevCommand` = `npm run dev`。
  - `build.frontendDist` = `../dist`，`beforeBuildCommand` = `npm run build`。
  - 窗口：1200 × 760，最小 980 × 680，居中。
  - bundle：`targets: "all"`，图标使用 `icons/` 下的 32/128 px 三件套。

## 3. 两种运行模式

| 模式 | 启动方式 | 数据存储 | 适用场景 |
| --- | --- | --- | --- |
| 浏览器预览 | `npm run dev` | localStorage + 示例数据 | 纯前端开发、UI 调试 |
| 桌面版 | `npm run tauri dev` | 本机 SQLite（`legal.db`） | 完整功能、联调 Rust 命令 |

前端通过 `src/lib/tauri.ts` 的 `isTauri()`（检测 `window.__TAURI_INTERNALS__`）自动区分环境，无需手动切换。

## 4. 打包说明

```bash
npm run tauri build
```

流程：`beforeBuildCommand`（tsc + vite build）→ Cargo release 编译（`src-tauri/Cargo.toml` 已配置 `lto`、`opt-level="s"`、`strip` 等体积优化）→ 生成安装包。

产物位置：`src-tauri/target/release/bundle/`。当前仓库 `src-tauri/target/` 已存在构建产物、`dist/` 已存在前端产物，说明本地已成功构建过。

仓库根目录提供两个启动脚本，但**均针对原作者机器写死路径**，需按本机调整：

- `启动律政工作台.bat`：
  - 硬编码 `PATH=E:\node-v24.19.0-win-x64\...`。

## 8. 常见问题

**Q：`npm run dev` 后浏览器打开页面但没有数据？**
这是浏览器预览模式，数据来自 localStorage 示例数据，首次访问会自动注入。法规/模板/待办均可正常体验；AI 助手与悬浮窗需要桌面版。

**Q：`npm run tauri dev` 报 Rust / MSVC 错误？**
确认已安装 Rust（`rustc --version` ≥ 1.77）与 Visual Studio Build Tools（含 C++ 工作负载）。可用 `.install/` 下的官方安装器补齐。

**Q：修改前端代码后桌面版不生效？**
Tauri 开发模式使用 `devUrl`（Vite 热更新），正常应即时生效；若修改了 `src-tauri/` 下的 Rust 代码，需重启 `npm run tauri dev` 重新编译。
