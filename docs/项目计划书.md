## 一、项目概述

### 1.1 背景与定位

法律从业者（律师、法务、调解员等）日常工作高度依赖"查法规、写文书、问 AI、译外文"，而现有工具分散在浏览器 / 翻译器 / 通用 AI 之间，数据与上下文割裂；通用 AI 回答无法保证法条真实可溯源，云端产品又存在敏感数据出网风险。

**法元**（工程名：legal-workbench，历史名：律政工作台 → 律衡，英文 Faron）是一个本地优先的法律工作一体化应用：把「法规库 + 文书智能体（小元）+ AI 问答 + 翻译 + 悬浮球选词」收进一个单机应用。**数据全在本机**，敏感文书不出内网；内置日美法库（152,940 条条文，来源 e-Gov / govinfo 官方）开箱即用——**主场景定位于涉外/跨境法律业务**：审阅涉日本、美国法律关系的合同与文书（中日合资、赴美投资、出口管制合规等），「文书智能体「小元」」可自主查真实法条、起草并交付 .docx 文书——形成"听懂委托 → 制定计划 → 自主调用工具 → 交付可溯源成果"的端到端闭环（数字员工）。中文全量法库列入 0.7.0 路线图（按权威公开源接入，禁止编造条文，见 docs/07 §八）；当前中文能力以内置示例法条 + 中文文书模板演示。

### 1.2 目标（0.6.0 验收口径）

- 功能面（0.5.0 已交付并出包）：法规检索（FTS5 优先）、AI 问答（RAG + 多会话 + 置顶悬浮窗）、文书智能体（规划 / function calling 工具循环 / .docx 交付 / 任务历史续跑 / 多智能体接力 / 人工闸门 / **确定性引用自检**）、API Key 加密落盘、交付文件打开 / 定位、悬浮球双向联动（含**关联查找法规**走主程序本地法库）。
- **0.6.0（品牌切换）**：`productName` / 窗口标题 / 侧栏 / 系统通知 / AI 提示词 / 悬浮球面板 / 交付物落款统一为「**法元 · Faron**」，文书智能体人设更名「**小元**」；工程名 / 主程序 exe / 进程 / `identifier` / 数据目录（`legal-workbench`、`com.legalworkbench.app`）不变；版本升至 0.6.0。
- 交付物（已出包，2026-09-06）：`发布包/法元_0.6.0_x64-setup.exe`（约 135 MB，内嵌法库 + 悬浮球 `win-unpacked-0.6.0`；移动端 `律政工作台-移动端/发布/法元-移动端-演示-v0.1.0-debug.apk`；0.4.x / 0.5.0「律衡」历史包同存于 `发布包/`）＋成套参赛文档（docs/06–09）。
- 参赛口径：在"AI 杭州 码动未来"赛事中呈现"从问答助手到可交付成果的数字员工"的完整演进（材料见 `docs/08`），主演示场景为涉外/跨境日美法务。
- 路线图（0.7.0+）：中文全量法库接入（docs/07 §八）、docx 表格化版式、任务并发、自动备份调度。

### 2.1 0.6.0 明确不做（边界）

- 云账号 / 多端同步 / 多人协作（本地优先是产品定位，不是缺陷）；
- **中文全量法库**（主场景已定位为涉外/跨境日美法务；中文法条按权威公开源接入，列为 0.7.0 路线图，见 docs/07 §八）；
- 移动端全量离线法库（490 MB 不适合手机默认分发）；
- 法规语义向量检索入口（15 万条不适合一次性全量 embedding，采用 FTS5 关键词召回 → Top 结果喂模型）；
- docx 复杂版式（表格化风险清单、批注修订版）——当前为最小 OOXML 子集；
- 自动备份定时调度（仍为配置 + 手动执行）。

## 三、用户场景与价值

1. **审涉日/美合同（端到端主场景）**：粘贴涉日合资、赴美投资、跨境贸易/出口合规类合同 → 文书智能体制定计划 → 自主检索本地内置的真实日美法条 → 起草《合同审查意见书》（中文输出，引用日美法条原文号 + 来源）→ 导出 .docx、引用可反查。
2. **写涉外文书**：起诉状 / 质证意见一键流水线，模板 + 法条双支撑，产出可二次编辑；检索词、法源、文书语言可按"涉日 / 涉美"分流。
3. **问 AI 要依据**：AI 问答注入真实法条，回答"引真条、不编造"；可一键"生成文书任务"转交智能体。
4. **查外法**：涉外业务查日本法 / 美国法典——"遺留分""trademark"国家内秒级命中，出处可标注（FTS5）。
5. **选词即用**：悬浮球在任意应用划词 → 翻译 / 关联查找（走主程序本地法库检索）/ 预填任务材料。
6. **中文法务延伸（路线图，0.7.0）**：接入中文全量法条后，同一套智能体能力服务于国内审合同 / 劳动纠纷等场景；当前中文以内置示例法条 + 中文文书模板演示。
7. **外出移动**：开庭 / 出差途中查法条、AI 摘要（移动端演示版）。

## 四、功能范围

### 4.1 桌面端（功能 0.5.0 已实现；0.6.0 品牌「法元 · Faron」）

首页总览（含最近文书）｜法规查询（国家筛选 + 重点预览 + FTS5 按需检索）｜模板库｜AI 问答（RAG / 多会话 / 置顶悬浮窗 / 一键转文书任务）｜**文书智能体「小元」（合同审查 / 起诉状 / 质证意见三条流水线；计划卡 / 工具循环 / 人工闸门 / 历史续跑 / 接力可视化；交付 .docx）**｜翻译（15 语言）｜待办 + 桌面提醒｜专注计时｜数据设置（主题 / 备份 / 还原 / AI 接口，Key 加密落盘）｜数据导入（Excel）。

配套：

- 悬浮球助手（Electron）：抓取模式（自动 / 手动拖入）、皮肤主题、双向联动、Key 混淆加密、系统代理；悬浮球拉起失败报错可见 + Job 脱离降级。
- 内置日美法库：日本 2,104 部（95,897 条）+ 美国法典 53 Title 与宪法（57,037 条）+ 中国示例 6 条；条文级共 152,940 条；首启自动装载（空库 / 仅示例自动补装，旧库先备份）。
- 检索增强：`laws` 表 FTS5 外部内容索引（trigram + BM25），≥3 字关键词优先 FTS，短词 / 异常自动回退 `LIKE`。

### 4.2 移动端（法元 · 轻量伴随入口，演示版已出）

- 法规：国家筛选 + 关键词 + 重点法规预览（数据源接口 local / remote 可切换，协议见 `src/laws/remote.ts`）；
- AI：多会话流式；翻译；模板 / 待办 / 专注 / 主题；
- 范围说明：数据存本机（localStorage）；演示口径为"法元的移动端生态演示"——不含桌面全量法库、Excel 导入、文书智能体任务与 .docx 交付（均为桌面能力）；在线检索源待服务端部署后启用（当前未启用）；法元品牌 APK 已重打（`发布/法元-移动端-演示-v0.1.0-debug.apk`，2026-09-06）。

### 4.3 数据资产

- 桌面预置库：`src-tauri/preload/legal_preload.db`（≈490 MB，git 忽略，随包分发）；
- 用户库：`%APPDATA%\com.legalworkbench.app\legal.db`；
- 加工链路：`法库ETL工作区/`（清洗 → 条文切分 → xlsx → 导入 / 预置），`ETL说明.md` 可复跑；
- 说明：法规原文版权归各官方源（e-Gov / govinfo / constitutioncenter / 国家法律法规数据库等），仅用于本地检索引用，分发注意合规边界。

## 五、技术方案

### 5.1 桌面端（现状）

Tauri 2（Rust）+ React 18 / TS + Vite 5 + SQLite（rusqlite bundled，WAL）；`laws_fts`（FTS5）；零依赖 OOXML docx 生成（`docx.rs`）；API Key XOR+hex 混淆（`keycrypt.rs`，启动迁移明文）；Electron 33 悬浮球；NSIS 打包（内嵌悬浮球与预置库）；双环境降级（桌面 SQLite / 浏览器 localStorage）。

### 5.2 文书智能体技术要点

- 接入：OpenAI 兼容 `/chat/completions`，流式 + `tools`（function calling）+ 结构化 JSON（计划卡）；
- 引擎：`src/lib/agent.ts`——规划（模型 / 演示预设）、执行（模型驱动工具循环 ≤6 轮 / 确定性演示）、四角色提示词（规划 / 检索员 / 起草员 / 质检员）；
- 工具集：`laws_search / law_by_id / laws_country_preview / template_load / translate_text`（真实本地法库，可溯源）；
- 状态与记忆：`tasks / task_steps / task_artifacts / mem_vectors` 表；任务历史可载入续跑；跨任务向量 / 关键词召回。

### 5.3 检索演进（已落地）

`LIKE 全表扫描 → FTS5(trigram) + BM25（0.4.0 已实现，短词回退 LIKE）`；语义级"第二通道"列入远期（15 万条全量 embedding 不现实，建议关键词召回 + Top 结果喂模型）。
