## 四、品牌与设计理念镜头（S0 / S6）详细要求

- **素材**：品牌标志原图 `logo.jpg`；应用图标 `src-tauri/icons/icon.png`（或从 `legal-workbench.exe` 取图标）；演示站 `#brand` 版块；安装包属性页图标。
- **三条理念的字幕必须与计划书 §1.2 逐字一致**：
  - 红色 —— **中国品牌**（红色是中国品牌最直接的视觉表达，也与法律印章的中国红相合）；
  - 渐变 —— **智能、科技**（明暗与方向的变化，让静态标志带上"运行中"的观感）；
  - 平行四边形 —— **高效、利落**（所有图形单元都由平行四边形构成，没有曲线与多余装饰，对应产品规则级校验、分步执行的工程性格）。
- **视觉规范**（片头/角标统一遵守）：主色用品牌红渐变 `#EA0202 → #8C1012`；标志一律等比缩放，不加投影 / 描边 / 其它渐变；白底版本优先；片头标志停留 ≥ 1.5 秒（让评委看清），不要做旋转 / 变形动画。
- **可用的现成资产**（已生成，直接用，不必自己拼）：
  - 片头：`assets/video/intro-dark.png`（1920×1080 深底，默认）/ `intro-light.png`（浅底备选）；
  - 落版：`assets/video/end-card.png`（标志 + 定位 + 版本 + "数据不出本机"）；
  - 竖版：`assets/video/intro-vertical.png`（1080×1920，30 秒切片用）；
  - 角标：`assets/video/corner-badge.png`（160×160 透明方块）/ `corner-badge-wide.png`（520×132 透明胶囊 + 品牌名）；
  - 演示站 `#brand` 版块可直接录屏（页头品牌标与 favicon 都已是标志，S6 用）。
- **不要出现**：旧版「法」字金标、旧品牌名「律衡」、与实际产品不一致的图标。

## 五、拍摄 / 剪辑红线（踩了要扣分）

- **别把 `/evolution`「自我进化」页当已实现功能拍**——它是 0.7.2 侧栏第 9 项的**方案稿可视化**，进片必须打"0.8.0 规划"角标；**不能说"联邦学习 / 强化学习 / 聚合大模型权重"**，要说"编排配方进化"。
- **中文法库口径**：只说"当前中文以内置示例 + 中文文书模板演示，全量在路上"，不说已覆盖中文全量。
- **移动端**：措辞为"法元的移动端生态演示"，不说"移动版法元"。
- **必命中词**：日本 `契約` / `民法` / `遺留分`，美国 `trademark` / `bankruptcy`（照 `docs/07` §七 抄）。
- **模型模式**：若走演示模式，**旁白必须先念**"当前未配置模型接口，计划为预设流水线，但工具调用真实执行"。
- **隐私**：录屏前清空"最近文书"与任务历史里的真实案卷、删掉数据库里的个人待办；API Key 只露 `enc:` 前缀。
- **反例先自验**：S5 的埋雷镜头必须在本机跑通一遍再开机录，确认自动点名的原文措辞。
- **悬浮球**：单独全屏录制再画中画贴入，避免双窗口抢焦点。
- **版本口径**：片尾落版写清"赛事版 0.7.3"；若视频发布时安装包尚未上传 GitHub Release，下载引导一律指向 `docs/08` 的提交包路径，不给失效直链。

2. 演示词全部取自 `docs/07` §七 必命中表；

4. 反例演示（库外条文号 → 自动点名）已在本机自验，确认输出文本；
5. 交付物导出路径可写、Word / WPS 可打开；悬浮球能拉起（托盘在）；
6. 确认演示机安装的是 **0.7.3**（图标为新品牌标志：任务栏 / 安装向导 / 关于页三处核对）；
7. 备份本次演示产出的 docx，避免现场误删；
8. 录屏设为 1080p / 30fps，关闭系统通知与来电弹窗。

**重新生成素材**（改了标志或版本号后复跑，确定性输出）：

```powershell
# 仓库根执行
powershell -ExecutionPolicy Bypass -File scripts/make-video-assets.ps1
# 可选：-Version "赛事版 0.7.4" -OutDir assets/video -Logo logo.jpg
```

**校验口径（已跑过，可复现）**：三套 SRT 编号连续、无重叠、不超成片时长、最快语速 3.2–3.8 字/秒（阈值 4.8）；`shotlist.csv` 13 列 × 10 行无错列；`shotlist.json` 十镜时长合计 180s 且镜次与 CSV 一致；六张 PNG 尺寸与内容外接框均在画布安全区内、角标四角 alpha=0。

> 边界（如实说明）：本包提供**分镜、字幕、配音稿与静态品牌素材**，不含录屏、配音音频与成片——那三样需要真人完成；静态素材不含动效，淡入 / 角标位置由剪辑软件实现；未使用任何生成式视频模型（产品镜头必须是真实屏录，生成画面不能作为参赛证据）。
