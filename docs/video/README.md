# 演示视频「可执行分镜包」

> 配套大纲：[../13-演示视频分镜脚本.md](../13-演示视频分镜脚本.md)（评分点映射、三个杀手镜头、拍摄红线、上场检查单）
> 素材来源：品牌标志 `logo.jpg` → 脚本 [`../../scripts/make-video-assets.ps1`](../../scripts/make-video-assets.ps1) 生成 `assets/video/` 全部静态素材
> 版本口径：赛事版 **0.7.3**（2026-09-14）

## 一、包里有什么

| 文件 | 用途 |
| --- | --- |
| `shotlist.csv` | **镜头表（Excel / 剪映导入用）**：镜次、段落、3 分钟版起止、时长、素材文件名、剪辑处理、画面要点、字幕要点、对应评分点、90 秒版取舍、30 秒竖版取舍、备注 |
| `shotlist.json` | 同一份镜头表的机器可读版（含成片规格、红线清单，便于后续用脚本生成剪辑指令） |
| `subtitles-3min.srt` | 主版 3:00 字幕 + 旁白时间轴（27 条） |
| `subtitles-90s.srt` | 送审版 1:30 字幕（10 条） |
| `subtitles-30s-vertical.srt` | 竖版切片 0:30 字幕（3 条，S5 → S7 → S6） |
| `narration-3min.txt` / `narration-90s.txt` | **配音逐字稿**（按镜次分段，给配音/口播用，不含时间码） |
| `../../assets/video/intro-dark.png` | 片头品牌帧 1920×1080（深底，默认） |
| `../../assets/video/intro-light.png` | 片头品牌帧 1920×1080（浅底备选） |
| `../../assets/video/end-card.png` | 落版 1920×1080（标志 + 定位 + 版本 + 数据不出本机） |
| `../../assets/video/intro-vertical.png` | 竖版片头 1080×1920（30 秒切片用） |
| `../../assets/video/corner-badge.png` | 角标 160×160（透明，白色圆角方块 + 标志） |
| `../../assets/video/corner-badge-wide.png` | 横版角标 520×132（透明，半透明胶囊 + 标志 + 品牌名） |

## 二、怎么用（剪映 / Premiere / DaVinci 通用）

1. **建工程**：主版 1920×1080 / 30fps；另建两个序列：送审版 1920×1080、竖版 1080×1920。
2. **导入镜头表**：`shotlist.csv` 用 Excel 打开按行拍摄 / 剪辑；剪映可直接把 CSV 当"拍摄清单"用（它不直接吃 CSV，按行手工对齐时间轴即可）。
3. **录屏命名**：全部放进 `raw/`，文件名严格按镜头表的"素材文件"列（例 `raw/S5-audit-fake-cite.mp4`），这样后续无论谁来剪都能对上号。
4. **字幕**：导入对应 SRT（剪映：文本 → 本地字幕 → 选择 SRT）。SRT 是**旁白时间轴**，若要画面内也显示要点，另建一条文字轨。
5. **品牌素材**：片头用 `intro-dark.png`（1.5 s 静帧 + 淡入），片尾用 `end-card.png`（2 s 静帧），全程右下角叠 `corner-badge.png`；品牌段（S6）可用 `corner-badge-wide.png`。
6. **变速**：按镜头表"剪辑处理"列——操作段 1.5–2×，**关于结论的镜头一律原速**（尤其 S5）。
7. **旁白**：先按 `narration-*.txt` 录音，再对字幕轴微调（差 0.2 s 以内不用动）。

## 三、录制前必做（照 docs/09 §五 + 本包红线）

1. 首启一次让法库与 FTS 索引就绪；离线试跑"检索 + 演示模式全流程"。
2. 演示词照 `docs/07` §七 必命中表（日 `契約` / `民法` / `遺留分`，美 `trademark` / `bankruptcy`）。
3. **S5 埋雷镜头先在本机跑通一遍**，确认"未覆盖自动点名"的原文措辞再开机录。
4. 确认演示机安装的是 **0.7.3**（任务栏 / 安装向导 / 关于页三处图标为新品牌标志）。
5. 录屏前清空"最近文书"与任务历史里的真实案卷；API Key 只露 `enc:` 前缀。
6. 1080p / 30fps 录屏，关闭系统通知与来电弹窗；悬浮球单独全屏录，再画中画贴入。

## 四、素材重新生成（改了标志或版本号时）

```powershell
# 仓库根执行；改了 logo.jpg 或版本号后复跑即可，图标与本包素材同源
powershell -ExecutionPolicy Bypass -File scripts/make-video-assets.ps1
# 可选参数：-Version "赛事版 0.7.4" -OutDir assets/video -Logo logo.jpg
```

脚本为确定性生成（同一输入 → 同一输出），不依赖任何生成式模型；标志一律等比缩放、不改色、不加投影描边。

## 五、已知边界（如实说明）

- 本包**只提供分镜、字幕、配音稿与静态品牌素材**，不含录屏素材、配音音频与成片——这三样需要真人录 / 真人配音。
- 静态素材是**图片帧**，不含动效；片头淡入 / 角标位置由剪辑软件实现。
- 未使用任何生成式视频模型（如 wan 系列）：产品镜头必须是真实屏录，生成画面无法作为参赛证据。
