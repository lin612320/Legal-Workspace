# 法元（Faron · 工程名 legal-workbench）功能演示报告（历史名：律政工作台 → 律衡）

**版本：v0.6.0「法元 · Faron」（桌面端 0.6.0 已出包）｜移动端为演示版（法元品牌 APK 已重打）｜报告日期：2026-09-06**

## 一、报告目的与范围

向使用者 / 评委演示法元 v0.6.0 的核心能力：**桌面端已实现的全部功能**按可操作路径逐项演示，重点为新增的**文书智能体「小元」（数字员工）端到端闭环**与**确定性引用自检**；**主演示场景为涉外/跨境日美法务**（审阅涉日/美合同与文书，引用本地内置日美官方法条）；**移动端**以演示版形态说明其定位与数据源接口设计。

> 口径说明：本文"操作 / 预期结果"基于 v0.6.0「法元」代码与安装包（`发布包/法元_0.6.0_x64-setup.exe`，2026-09-06 出包，约 135 MB；0.5.0「律衡」为历史包）；真机逐项验收与实测数据按 `docs/07-真机验收清单.md` + `docs/09-真机验收执行指引.md` 执行并回填，录屏 / 截图位待回填。

## 二、产品一句话

本地运行的涉外/跨境法律工作"数字员工"：**法规检索（FTS5）+ 文书智能体（自主查真实法条、起草并交付 .docx）+ AI 问答 + 翻译 + 悬浮球选词即用**，内置日美法库 15.3 万条条文（装机即用、无需联网导入），数据全在本机。

## 三、桌面端功能演示清单（操作 / 预期结果）

### 1. 安装即用（首启演示，约 1 分钟）
- 操作：安装 `发布包/法元_0.6.0_x64-setup.exe` → 首次启动。
- 预期：自动拉起悬浮球托盘；进入「法规查询」显示"内置法规 152,940 条"；左侧导航含 10 版块（含 **AI 问答** 与 **文书智能体**）；窗口/安装包显示品牌「法元」。

### 2. 法规查询 · FTS5（重点演示，约 2 分钟）
- 操作：国家下拉选 **🇯🇵 日本** → 左侧预显示重点法规（民法 / 会社法 / 地方税法…）→ 输入 `遺留分`（或 `契約`）；再切 **🇺🇸 美国** 输入 `trademark`。
- 预期：国家内命中（全库含"契約"4,565 行），左列表右正文、命中可溯源；FTS5 优先、不足 3 字自动回退 `LIKE`；按需检索不卡顿。

### 3. 文书智能体「小元」· 涉日/美合同审查（本次重点，约 4 分钟）
1. 进「文书智能体（小元）」→ 任务类型"合同审查"→ 粘贴涉日/美合同（点「填入示例合同」亦可）→ **① 制定计划**：小元产出**计划卡**（模型驱动时为 LLM 结构化规划；未配置模型则自动进入**演示模式**，工具仍真实执行）。
2. 可编辑计划（步骤 JSON / 检索关键词与国家）→ **② 开始执行**。
3. 预期：进度条展示**模型自主调用真实工具**（`laws_search → law_by_id → template_load` 等，≥3 次）；演示用检索词落在库内必命中词（如日本 `契約 / 民法`、美国 `trademark`，见 docs/07 §七）；"本次引用法条"列表附篇名 / 条文号 / 来源（e-Gov / govinfo），**可反查、禁编造**；计划卡顶部可见"规划 → 检索员 → 起草员 → 质检员"接力链与状态徽标。
4. 任务完成后查看质检步骤末尾【引用自检 · 确定性规则】结论与交付物「四、引用自检（确定性规则校验）」章节（模型模式与演示模式都会执行）→ **导出 .docx** → 点「打开文件」（Word / WPS 打开）与「在文件夹中显示」。
5. 回首页：**最近处理的文书**出现该记录，行内可「打开」「删除」。
6. 可选：任务执行到"需人工确认"步骤会暂停，点「继续」放行；执行中可「暂停」，任务刷新后可经**任务历史**载入续跑。

### 4. AI 问答 + 交接桥（约 1 分钟）
- 操作：进「AI 问答」选"审合同"提问；得到回答后点右上 **📄 生成文书任务**。
- 预期：自动跳转文书智能体并预填交接内容（问题 + 结论）、匹配任务类型；可继续制定计划生成交付文书——演示"咨询 → 交付"闭环。

### 5. 悬浮球助手（选词即用，约 1 分钟）
- 操作：任意应用选中文字 → 悬浮球弹窗 → 翻译 / **关联查找法规**（走主程序本地 15 万条法库检索并回显命中）/ 询问 AI；拖文字到球（手动模式）；在文书智能体页划词会自动预填为任务材料。
- 预期：内置 Key 混淆 + 系统代理，办公网络开箱即用；点顶栏「🎯 悬浮球」若拉起失败会**弹窗给出原因**（不再无声失败）。

### 6. 模板 / 翻译 / 待办 / 专注（各约 30 秒）
- 模板库：内置起诉状 / 委托书等，分类筛选、自建、删除（内置不可删）；
- 翻译：免费接口开箱即用，15 种语言；
- 待办：截止时间 + 到期桌面弹窗；专注计时：25/5/15 番茄钟 + 系统通知。

### 7. 数据设置与安全（约 1 分钟）
- AI / 翻译接口配置（AI 问答与文书智能体共用；`ai.api_key / translate.api_key` **加密落盘**，`enc:` 前缀，启动自动迁移历史明文）；
- 手动备份 / 还原；数据导入（Excel：法规 / 模板，演示"新增 N 条、跳过 M 条"）。

## 六、演示亮点话术（可复用）

1. "**15 万条真实日美法条装机即用、引用可反查**"——省去联网导入，回答与文书不编法条（涉外业务主场景：审涉日/美合同直接引用本地官方法条）；
2. "**按国家看、按词秒查**"——FTS5 检索 + 重点法规预览，切页不卡；
3. "**把涉外合同交给小元**"——数字员工听懂委托 → 计划卡 → 自主连续调用真实工具 → 交付可打开 .docx，引用经**确定性规则自检**（非模型自查）；
4. "**人在环上**"——计划可编辑、步骤可设人工确认、失败即停，AI 可管可控；
5. "**数据不出本机、Key 加密落盘**"——本地优先与安全口径；
6. "**中文法库在路上**"——中文全量法条按权威公开源接入为 0.7.0 路线图（docs/07 §八），当前以中文模板文书 + 内置示例演示，口径如实、不夸大。
