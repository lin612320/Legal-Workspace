## 快速查阅

- 产品现状一句话：**法元 = 本地优先的法律工作一体化应用**（Tauri 2 桌面 + Electron 悬浮球，工程名 legal-workbench），内置日美法库 152,940 条条文装机即用；**文书智能体「小元」**听懂委托 → 制定计划 → 自主调用本地工具查真实法条 → 交付可溯源 .docx 文书（确定性引用自检，非模型自查）。
- 参赛口径与对外文案：见 [08-参赛材料包.md](08-参赛材料包.md)（五维自评、竞品、商业模式、演示脚本、答辩 Q&A）。
- 真机验收与实测回填：按 [07-真机验收清单.md](07-真机验收清单.md) 检查、[09-真机验收执行指引.md](09-真机验收执行指引.md) 执行并回填。

> 历史副本提示：`DEMO/` 与工作区早期目录保留的是旧版快照（0.1.0/0.2.0 时代，文档停留在"8 版块、无智能体"），**不能作为当前产品现状引用**；现状一律以本仓库（feature-悬浮球外观）根目录 README / CHANGELOG 与本 docs 目录为准。
