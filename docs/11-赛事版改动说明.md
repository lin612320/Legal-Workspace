> 主版本（dev）不受影响；本文记录赛事版相对主版本的全部差异，作为赛事演示口径的“唯一事实来源”。

## 二、法规模块改造（本版重点）

### 2.1 用户路径

```
法规查询(/laws)
├── [📚 按法浏览] 选国家(🇯🇵日本/🇺🇸美国/🇨🇳中国)
│     └── 国家专属页：政体/国体/法律体系概览 + 按法律领域分组的法律列表（原文法名+中文译名）
│           └── 点击法律名 → /law/:title 整部法浏览页
│                 ├── 元信息：双语名称/领域/简介/条文数/来源
│                 ├── 完整条文：默认官方原文、可选中复制、章节标题
│                 ├── 条文跳转：阿拉伯数字 / 中文数字 / 罗马数字（Article·Sec / Amendment / §）
│                 └── 打印 / 另存 PDF（WebView 打印，零新增依赖）
└── [🔍 关键词检索] 中文输入可命中 title_zh / content_zh / 元数据译名（FTS 无命中回退 LIKE）
```

- 旧“关键词命中条文 → 逐条阅读”的搜索体验保留（在检索模式下），并为“点开整部目标法律”提供一键入口（修复合规检索“点不到整法”的问题）。
- 正文可复制：全局 `user-select` 放开为 `text`，仅侧栏/顶栏/按钮等交互壳禁用。

### 2.2 数据模型（迁移自动执行，老库/预置库兼容）

| 变更 | 说明 |
| --- | --- |
| `laws.title_zh` / `laws.content_zh`（TEXT，可空） | 条文级中文译名 / 译文；Excel 导入与整法页“查看译文”开关共用 |
| `laws_meta(title PK, country, domain, name_zh, name_orig, intro)` | 整部法元信息：中文译名 / 原文名 / 法律领域 / 简介 |
| `country_intro(country PK, intro)` | 国家页顶部概览（政体 / 国体 / 法律体系），日/美/中各一行 |
| `idx_laws_title ON laws(title)` | 整法查询 / 分组提速 |

- 首启播种（仅当表空）：日/美/中重点法元数据（日本国宪法、日本民法/刑法/公司法/劳动基准法/著作权法/民诉/刑诉、美国宪法、美国法典 Title 42/15/10/26/7/16、中华人民共和国民法典）与国家概览。
- 检索 SQL：国家判定 CASE 改为**表别名限定**（`country_sql(alias)`），避免 join 后 `title` 歧义；检索结果回带 `title_zh`。

### 2.3 后端新命令

| 命令 | 返回 |
| --- | --- |
| `laws_country_home(country)` | 国家概览 + 领域分组法律列表（含 `title_zh` / 条文数），`未分类` 置后 |
| `law_page(title)` | 整部法元信息 + 完整条文（含 `content_zh`，按 id 顺序，上限 8000 条） |

### 2.4 真实译文口径（不编造法条）

- 术语：中文译名/译文仅接受**可溯源来源**；内置元数据的 `name_zh` 为通行的中文法律名称，`intro` 为事实性简介（不含自拟条文译文）。
- **已内置（条文级）**：美利坚合众国宪法官方中译——由源数据官方中译 PDF（`法律数据库（美.日）/…/pdf原件/美利坚合众国宪法/美利坚合众国宪法_译文.pdf`，美国国务院官方译本，正文 Preamble + Article I–VII）经“段落结构对齐”脚本（按「第X条 / 第X款」标题切分并与预置库 `article_no` 逐条比对，25/25 全对齐后才生成）产出 `src-tauri/src/data/us_const_zh.json`；启动迁移（`enrich_us_constitution_zh`）按 `article_no` 幂等回填 `laws.content_zh`，仅补空值、不覆盖导入译文。
- **未内置（需导入）**：该官方译本不含 27 条修正案；日本法、美国法典各 Title 无现成译文。需要时以可溯源来源按 `title` / `article_no` 整理为带 `content_zh` 列的 Excel 导入（或并入预置库后重新打包），应用不生成无依据译文。

## 三、悬浮球（floating-ball）修复

1. **拖拽不再“越拖越大 / 漂移”**：主进程按“起始位置 + 光标增量”移动并**钳制在主屏工作区内**；渲染层在 mouseup / 失焦 / dragend 时兜底清理 `dragging`、`drop-hover` 卡死态（卡死态会表现为球体停留在放大 / 换图标观感）。
2. **结果区按钮不常驻**：⏹ / ⧉ / 🗑 仅在使用时显示，避免“输入区上方常驻图标”。
3. **问答后清空结果**：新任务开始即清空；新增 🗑 一键清空；抓取 / 推送新文本自动清上一轮结果。
4. **提问面板“多次拖拽慢慢变大”根治（2026-09-07）**：面板窗口与悬浮球窗口均固定尺寸（`min = max`、`resizable:false`），并启动 **800ms 尺寸看门狗**——任何系统 / 未知途径把窗口改大都自动拉回；面板拖动改为增量并钳制在主屏内。
5. **主面板直接提供「自动抓取 / 手动拖入」快捷切换**：与“设置”抽屉联动（点击即生效并持久化）；并修复此前 `pendingGrabMode` 未声明导致“未开过设置抽屉时点击无反应”的问题（无头 Electron 点击测试通过）。
6. **版本升至 1.0.1**：托盘悬停提示显示版本号，可在单实例机制下确认运行的是新包（避免旧常驻进程顶掉新包造成假修复）。
