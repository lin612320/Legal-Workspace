## 八、中文法库接入方案（重要）

现状：预置库仅含日美法 + 6 条中国示例；「文书智能体」默认 `country=中国` 在未接入全量中文法条时命中有限。

接入路径（**禁止编造条文，一律使用权威公开源全文**）：

1. 取得真实全文：从公开权威来源下载现行法全文文本（如国家法律法规数据库 flk.npc.gov.cn、司法部法律法规数据库 gov.cn 等；注意校订日期与现行有效版本）。
2. 组织导入表：列格式与「数据导入」一致：`title / chapter / article_no / content / source`（chapter 可留空，source 填来源网址）；可参考 `法库ETL工作区` 现有日本/美国解析器改造为 `cn_parse.mjs`。
3. 导入方式二选一：
   - A. 运行时导入：律政工作台 →「数据导入」→ 法规（laws 表）→ 选择该 xlsx，预期新增 N 条；
   - B. 并入预置库：按 `法库ETL工作区/ETL说明.md` 流程把中文行并入后重建 `legal_preload.db`，随安装包分发（FTS5 会在首启自动建索引）。
4. 建议首批范围：以评审主场景为准，例如《中华人民共和国民法典》（重点合同编/人格权编条款）、《中华人民共和国劳动法》《中华人民共和国劳动合同法》《中华人民共和国著作权法》等。
5. 导入后验证：法规查询选 🇨🇳 中国检索如 `第五百零二条`、`劳动合同`，确认命中数与来源列；再跑一遍 §三 的智能体流程，观察"引用溯源"换为中文法条。

## 九、已知限制与风险（如实写入答辩）

- FTS5 索引为运行时构建，15 万条库首次启动有一次性耗时；旧版本升级首次启动同。
- 文本长度超上下文时（超长合同）暂未自动分块——演示用 ≤ 4 千字材料，超长场景在路线图中。
- `open_file` 使用白名单扩展名（docx/doc/md/txt/xlsx/xls/pdf/html/csv），防止误开任意文件。
- API Key 混淆（XOR+hex）为防误读方案，非密码学加密；答辩口径建议表述为"避免明文落盘/防误读"，不夸大。
