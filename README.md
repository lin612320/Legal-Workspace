# 律政工作台（Legal Workbench）

> 法律工作者本地桌面助手 —— 单机运行，数据全部保存在本机。

律政工作台是一个面向律师、法务等法律工作者的本地桌面应用，围绕日常办案流程提供法规查询、文书模板、AI 辅助、翻译、待办提醒等一体化工具。当前版本 `0.1.0`，属于功能骨架已就位、部分模块待完善的演示版（DEMO）。

## 技术栈

| 层 | 技术 | 说明 |
| --- | --- | --- |
| 桌面壳 | Tauri 2 | Rust 编写，负责窗口管理、本地命令桥、文件系统与数据库访问 |
| 前端框架 | React 18.3 + TypeScript 5.5 | 严格模式，函数组件 + Hooks |
| 构建工具 | Vite 5.4 | 开发服务器端口固定 `1420`，构建目标 `es2021` |
| 路由 | react-router-dom 6.26 | `HashRouter`，8 个版块 + 悬浮窗路由 |
| 数据库 | SQLite（rusqlite 0.31 bundled） | 本地单文件 `legal.db`，WAL 模式 |
| 样式 | 手写 CSS | 无 UI 组件库，基于 CSS 变量设计令牌 |

## 功能一览

左侧导航共 8 个版块：

1. **首页总览**：今日待办、统计卡（今日/进行中/已超期）、超期横幅、常用功能快捷入口。
2. **法规查询**：按关键词检索法规条文（篇名/条文号/章节/内容），左列表右正文阅读。
3. **模板库**：内置 5 份法律文书模板，支持分类筛选、自建模板、删除（内置模板不可删）。
4. **AI 助手**：OpenAI 兼容接口流式对话，内置「通用 / 审合同 / 审质证」三种模式，支持大窗口 ⇄ 置顶悬浮窗切换。
5. **翻译**：内置免费接口（Google gtx，无需 Key，开箱即用），可选配置付费接口，支持 15 种语言与自动检测。
6. **待办提醒**：待办增删改查、截止时间、提前提醒、桌面弹窗开关、多种筛选视图。
7. **数据设置**：AI / 翻译接口配置、手动备份、自动备份配置、数据库还原、偏好设置。
8. **数据导入**：预留 Excel 导入入口（当前为占位页，解析逻辑待实现）。

> 各版块的实现细节与完成状态见 [docs/02-功能模块.md](docs/02-功能模块.md)。

## 运行模式（重要）

本项目支持两种运行环境，同一套前端代码自动降级：

- **桌面版（Tauri）**：数据通过 Rust 命令读写本地 SQLite，功能完整。
- **浏览器预览版（Vite dev 直接打开）**：不加载 Tauri，数据降级到 `localStorage` 示例数据，便于纯前端开发调试。

检测逻辑位于 `src/lib/tauri.ts` 的 `isTauri()`（判断 `window.__TAURI_INTERNALS__` 是否存在）。

## 快速开始

```bash
# 安装依赖（Node.js 20+，建议 v24）
npm install

# 浏览器预览模式（仅前端，数据为示例数据）
npm run dev        # 打开 http://localhost:1420

# 构建前端产物
npm run build      # tsc 类型检查 + vite build，输出 dist/

# 桌面版开发（需 Rust 工具链，见 docs/04-开发与构建指南.md）
npm run tauri dev

# 打包桌面安装包
npm run tauri build
```

> 注意：仓库根目录的 `启动律政工作台.bat` / `启动律政工作台.vbs` 是浏览器预览模式的启动脚本，内部写死了 `E:\DEMO`、`E:\node-v24.19.0-win-x64` 等绝对路径，需按本机实际路径调整后才可使用。
