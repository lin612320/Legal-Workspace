# 法元 · Faron

> 法律工作者本地桌面助手 —— 单机运行，数据全部保存在本机。
> 品牌口径：主品牌 **法元 · Faron**（中文名「法元」，英文名 Faron）；**0.6.0 起品牌由「律衡」切换为「法元 · Faron」**（0.4.1–0.5.0 曾以「律衡」为传播名，0.5.0 安装包即用「律衡_0.5.0」命名）。工程与历史名：legal-workbench / 律政工作台 / 律衡——0.4.x 及更早安装包用「律政工作台_0.4.x」命名。进程标识与数据目录（`legal-workbench.exe`、`com.legalworkbench.app`）保持不变，升级不丢数据。图标暂沿用 0.5.0「律」字标，0.6.0 出包前重设计。

法元（工程名 legal-workbench，历史名：律政工作台 / 律衡）是一个面向律师、法务等法律工作者的本地桌面应用，围绕日常办案流程提供法规查询、文书模板、AI 辅助、文书智能体、翻译、待办提醒等一体化工具。**配套「悬浮球助手」桌面常驻小球**，选中文字即可翻译、检索或询问 AI。当前版本 `0.6.0`（品牌「法元 · Faron」）：0.4.0 起安装包**内置日美法律数据库**（15.3 万条条文，装机首启即用）并新增**文书智能体**（端到端任务交付，可导出 .docx；人设 0.4.1 起命名「小衡」，0.6.0 随品牌更名「**小元**」）；0.4.2 为文书智能体新增**确定性引用自检**（质检为代码级规则校验，非模型自述）；0.5.0 安装包/产品名正式更名「律衡」（工程名 legal-workbench 不变），并让悬浮球「关联查找法规」真正可用（经主程序在本地 15 万条法库检索并回显命中）；**0.6.0 品牌切换为「法元 · Faron」并已出包**（2026-09-06：桌面 `发布包/法元_0.6.0_x64-setup.exe`、移动端 `律政工作台-移动端/发布/法元-移动端-演示-v0.1.0-debug.apk`、悬浮球便携版同步；工程名 / 主程序 exe / 进程 / 数据目录不变；0.4.x / 0.5.0「律衡」历史包保留）。

> 本文档为 **`feature/赛事版`** 分支口径（赛事演示版）：在 0.6.0「法元 · Faron」基础上移除「AI 问答」「专注计时」两个版块，并把法规查询升级为“国家 → 领域 → 整部法浏览”（双语法名、条文跳转、打印 PDF、正文可复制、中文检索）。与主版本差异见 [docs/11-赛事版改动说明.md](docs/11-赛事版改动说明.md)。
>
> **0.7.0 赛事版增量（2026-09-09，本分支在 0.6.0 之上的新一轮升级，详见 [CHANGELOG.md](CHANGELOG.md)）**：① 文书智能体任务扩展为 **5 类**——合同审查 / 起诉状 / 证据目录 / 质证意见 / 代理词（证据目录交付 .docx 原生表格）；② **知识图谱**（本地 SQLite）：涉外案由优先的人工策展种子 → 按任务材料命中案由 → 图谱骨架驱动**规划与编排**（要件不漏、法域自动限定）→ 交付物追加**法条适用性二段校验** → 任务命中法条自动登记为候选边、**人工确认后才作为规划依据**，Agent 页提供分层可视化图谱面板；③ **多模态任务材料**：DOCX / PPTX / XLSX / TXT / MD / CSV 本地离线提取，PDF / 图片走支持视觉/文件输入的模型（转录标注"非原文"；**音频不在范围**）。

## 技术栈

| 层 | 技术 | 说明 |
| --- | --- | --- |
| 桌面壳 | Tauri 2 | Rust 编写，负责窗口管理、本地命令桥、文件系统与数据库访问 |
| 前端框架 | React 18.3 + TypeScript 5.5 | 严格模式，函数组件 + Hooks |
| 构建工具 | Vite 5.4 | 开发服务器端口固定 `1420`，构建目标 `es2021` |
| 路由 | react-router-dom 6.26 | `HashRouter`，10 个版块 + 悬浮窗路由 |
| 数据库 | SQLite（rusqlite 0.31 bundled） | 本地单文件 `legal.db`，WAL 模式 |
| 悬浮球 | Electron 33（`floating-ball/` 独立应用） | 桌面小球 + 选词翻译/检索/AI，与主应用文件桥接 |
| 样式 | 手写 CSS | 无 UI 组件库，基于 CSS 变量设计令牌，支持日间/夜间主题 |

## 功能一览

左侧导航共 8 个版块（赛事版口径；历史主版本 10 版块含「AI 问答」「专注计时」，已按赛事演示精简）：

1. **首页总览**：今日待办、统计卡（今日/进行中/已超期）、超期横幅、常用功能快捷入口、最近处理的文书。
2. **法规查询**：**双模式**——「📚 按法浏览」与「🔍 关键词检索」。
   - **按法浏览**：选择目标国家（🇯🇵 日本 / 🇺🇸 美国 / 🇨🇳 中国）→ 进入**国家专属页**，顶部展示该国**政体 / 国体 / 法律体系概览**，正文按**法律领域**分类列出法律名称（原文法名 + 中文译名，可部分列表预览）；点击法律名进入**整部法浏览页**（上方为该法元信息：双语名称 / 领域 / 简介 / 条文数，下方为完整条文）。
   - **整部法浏览页**：条文默认展示官方原文、可选中复制；顶部提供**条文跳转**（支持输入阿拉伯数字 / 中文数字 / 罗马数字，如 `103`、`百三`、`1.2`）；支持**打印 / 另存 PDF**；库内条文含译文列时可一键切换查看中文译文。
   - **关键词检索**：按国家限定关键词检索（FTS5 优先、LIKE 兜底，命中最多前 500 条），**支持中文输入**——可命中中文译名与译文（如输入“宪法”“民法典”）；命中结果按篇名分组，并可直接“打开整部法律”。
   - **出厂内置日美法库**：日本 2,104 部现行法 + 美国法典 53 个 Title + 美利坚合众国宪法，条文级共 152,940 条（来源 e-Gov / govinfo / constitutioncenter.org）。重点法已内置双语法名与领域/简介（`laws_meta` / `country_intro`）；**美国宪法官方中译已按条文级内置**（Preamble + Article I–VII 共 25 段，与官方 PDF 对齐入库，非生成内容）；其余法律的中文译文可经 Excel 导入补充（新增 `title_zh` / `content_zh` 可选列）。
3. **模板库**：内置法律文书模板，支持分类筛选、自建模板、删除（内置模板不可删）。
4. **文书智能体「小元」（数字员工）**：把合同/案情交给小元，按流水线交付文书——模型结构化**制定计划卡**（可编辑），检索类步骤走**自主工具调用循环**（`laws_search / law_by_id / template_load / translate_text` 等，只引用工具真实返回的法条），支持人工确认闸门、任务历史载入续跑与执行日志；**质检含确定性引用自检**（规则校验：识别正文条文号并逐一与工具返回法条比对，未覆盖引用自动点名提示，非模型自述），交付物实时预览并可**导出 .docx**（记入首页「最近文书」，浏览器版下载 .md）。未配置模型时进入演示模式（预设流水线 + 工具真实执行）。**0.7.0 起**：
   - **5 类任务**：合同审查 / 起诉状 / 证据目录 / 质证意见 / 代理词——每类有独立输出骨架（`KIND_GUIDES`）；证据目录等表格型交付支持 Markdown 表格 → **.docx 原生表格**；
   - **知识图谱规划与编排**：任务材料自动匹配涉外案由（货物买卖 / 合资经营等）→ 图谱「案由 → 构成要件 → 请求权基础 / 证据 / 争点」骨架驱动计划卡，杜绝要件遗漏；交付物与 QA 步骤叠加**法条适用性校验**（引用是否落在案由请求权基础范围，二段自检）；
   - **图谱自进化（人工确认制）**：任务真实命中的法条自动登记为低置信度候选边，Agent 页可视化图谱中以虚线展示，点 ✓ / ✕ 人工确认后才作为后续规划依据；图谱由**人工策展种子 + 任务观测 + 人工确认**构成，全部存本机、可溯源；
   - **多模态材料输入**：任务材料面板可导入 DOCX / PPTX / XLSX / TXT / MD / CSV（本地离线提取文本）与 PDF / 图片（需配置支持视觉/文件输入的模型；转录文本标注「模型解析，非原文」；音频不在范围）。
5. **翻译**：内置免费接口（Google gtx，无需 Key，开箱即用），可选配置付费接口，支持 15 种语言与自动检测。
6. **待办提醒**：待办增删改查、截止时间、提前提醒、到期桌面弹窗（系统通知）、多种筛选视图。
7. **数据设置**：AI / 翻译接口配置（供智能体与翻译使用）、日间/夜间主题、手动备份、自动备份配置、数据库还原。
8. **数据导入**：从 Excel 批量导入法规 / 模板数据（中英文表头；法规支持可选 `title_zh` / `content_zh` 译文列）。

> 各版块的实现细节与完成状态见 [docs/02-功能模块.md](docs/02-功能模块.md)。

### 悬浮球助手（floating-ball）

桌面常驻小球，与主应用双向联动：

- **选中即用**：鼠标选中任意文字 → 悬浮球弹窗一键**翻译 / 关联查找 / 询问 AI**。
- **抓取模式可切换**：默认「自动抓取」（选中文字松开即弹面板）；可切到「手动拖入」——不主动抓取，把选中文字拖到悬浮球或面板内即触发。
- **推送给主应用**：悬浮球可将选中文字直接推送给「文书智能体」预填为任务材料（赛事版已移除独立 AI 问答栏；“询问 AI”在悬浮球面板内独立完成）。
- **外观可定制**：多套球皮肤与面板主题（内置皮肤选择窗）、悬停对话气泡。
- **随主应用联动**：法元启动时自动拉起悬浮球；顶栏「🎯 悬浮球」按钮唤起面板；悬浮球也可自动拉起打包版 `legal-workbench.exe`。
- **开箱即用**：内置共享 AI Key（运行时解码，不落明文）与配置加密；请求走系统代理，办公网络无需额外设置。
- **独立可用**：悬浮球也可脱离主应用单独运行（便携版 `悬浮球助手`）。

## 运行模式（重要）

同一套前端代码自动降级：

- **桌面版（Tauri）**：数据走 Rust 命令读写本地 SQLite，功能完整；启动时自动拉起 Electron 悬浮球。
- **浏览器预览版（Vite dev 直接打开）**：不加载 Tauri，数据降级到 `localStorage` 示例数据；悬浮球相关功能通过 Vite 桥接插件联动。

检测逻辑位于 `src/lib/tauri.ts` 的 `isTauri()`（判断 `window.__TAURI_INTERNALS__` 是否存在）。

主应用查找悬浮球按以下顺序（满足其一即可，均支持子目录递归）：

1. 环境变量 `FLOATING_BALL_DIR` 指向的目录（开发/自定路径）
2. 主程序 exe 同目录 / `resources` 子目录（发布形态：悬浮球随包装入 `win-unpacked-<版本>` 版本化目录，升级不覆盖旧文件）
3. 主程序 exe 旁 `_up_` 目录（兼容旧版安装包布局）
4. 项目仓库内 `floating-ball`（开发形态，`CARGO_MANIFEST_DIR` 上一级）
5. 用户桌面 `floating-ball`（旧开发形态兜底）

法元 → 悬浮球命令通过共享控制文件 `%APPDATA%\floating-ball\from-workbench.json` 下发（show / hide / prefill / translate / quit），悬浮球常驻轮询执行。

## 快速开始

```bash
# 安装依赖（Node.js 20+，建议 v24；Rust 工具链用于桌面版）
npm install

# 浏览器预览模式（仅前端，数据为示例数据）
npm run dev        # 打开 http://localhost:1420

# 桌面悬浮球依赖：进入 floating-ball 单独安装
cd floating-ball && npm install && cd ..

# 一键联调：Vite 前端 + 悬浮球（见 scripts/dev-with-ball.cjs）
npm run dev:all

# 构建前端产物
npm run build      # tsc 类型检查 + vite build，输出 dist/

# 桌面版开发（需 Rust 工具链，见 docs/04-开发与构建指南.md）
npm run tauri dev

# 打包桌面安装包（NSIS，内含悬浮球 win-unpacked）
npm run tauri build
```

## 内置法库与数据说明

- 0.3.2 起安装包内置预置库（`src-tauri/preload/legal_preload.db`，约 490 MB，**git 忽略不入库**）；首次启动检测到用户数据目录无 `legal.db` 时自动拷贝装载。
- 重新打包带库版本前，需先按 `法库ETL工作区/ETL说明.md` 生成/刷新预置库；换环境时把 `legal_preload.db` 放到 `legal-workbench.exe` 同目录，便携版同样自动装载。
- **升级提示**：老用户已有本地库时不会覆盖其数据；如需强制换用内置库，退出应用后删除 `%APPDATA%\com.legalworkbench.app\legal.db` 再启动。
- 规模提示：库内法规正文约 350 MB。0.4.0 起关键词检索**优先走 FTS5**（trigram 分词 + BM25 相关度），不足 3 字或 FTS 不可用时自动回退 `LIKE`；15 万条不适合一次性全量 embedding，RAG/智能体采用"关键词召回 → Top 结果喂给模型"。
- **0.4.0 安全说明**：`ai.api_key / translate.api_key` 加密落盘（`enc:` 前缀，XOR+hex 混淆，与悬浮球同源思路），旧明文在启动时自动迁移；交付文件可通过 `open_file / reveal_in_folder` 命令打开/定位（扩展名白名单）。

## 打包与发布

- 主应用安装包：`npm run tauri build` → `src-tauri/target/release/bundle/nsis/法元_0.6.0_x64-setup.exe`（已出包至 `发布包/`，约 135 MB，2026-09-06；0.5.0「律衡」历史包同目录保留）。安装包内嵌悬浮球与法库预置库，装入**版本化子目录**（如 `win-unpacked-0.6.0`），升级安装不会与正在运行的旧悬浮球发生文件占用冲突。
- 悬浮球便携版（独立使用）：在 `floating-ball/` 下 `npm run dist` → `floating-ball/dist/悬浮球助手 1.0.0.exe`。
- 完整交付物统一放入 `发布包/`。
